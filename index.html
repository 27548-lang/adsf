    Supabase Integration & Cloud Sync

    Connect your free Supabase project to automatically back up and sync your tasks across devices in real-time.

    Supabase SQL Setup Snippet

    Copy & paste this snippet into your Supabase Dashboard -> SQL Editor to generate the required database table:

    CREATE TABLE IF NOT EXISTS tasks (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  description TEXT,
  category TEXT,
  priority TEXT,
  dueDate TEXT,
  dueTime TEXT,
  estimatedTime INT,
  status TEXT,
  completed BOOLEAN DEFAULT FALSE,
  subtasks JSONB DEFAULT '[]'::jsonb,
  recurring TEXT DEFAULT 'None',
  created TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE tasks ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public full access" ON tasks FOR ALL USING (true);

    GitHub Repository Deployment Guide

    Data Backup & Export

    Save your current tasks locally as JSON.

    How to Save & Publish on GitHub Pages:

    1. Download Code File: Click below to download this web app file as index.html.
    2. Create GitHub Repo: Go to github.com/new and create a repository named taskflow-pro.
    3. Upload index.html: Click "uploading an existing file" inside your new repository and upload the index.html file.
    4. Enable GitHub Pages: Go to Repo Settings -> Pages, set Source branch to main (or master) and click Save. Your web app will be live globally!
